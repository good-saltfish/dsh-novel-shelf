# 小说书架 · AI 陪读

阅读器右侧栏里多了一块 **AI 陪读**：开着之后，AI 每隔一段时间就着「你刚读到的内容」吐槽一句。默认关闭——不开就一次都不会调用模型。

## 怎么用

1. 打开右侧栏的「小说书架」，进一本书。
2. 点底部工具栏的 **「AI 陪读」** 展开面板。
3. 点右上角开关打开（按钮会从「已关闭」变成「已开启」）。**开关一开就立刻说一句**，不用等一个周期，也不用等面板展开。
4. 想立刻再听一句就点 **「现在就说」**。
5. 收起面板后，右下角仍站着那个陪读人物，点它展开气泡看历史吐槽。

## 模型怎么配

点底部工具栏的 **「模型」**：

- **选 DSH 已注册的 provider**：下拉里列出 `llm.listConfigurableProviders()` 与 `llm.listProviders()` 里的 provider，选中后下拉里列它的模型。若某个 provider 还没配好（比如 DeepSeek 账号没登录），它自己的错误会直接显示在面板里。
- **自填端点**：填 baseURL + API key + 模型名，走 OpenAI 兼容的 `/chat/completions`，花费记你自己的账。
- **测试**：「测试」按钮会真的发一次最小请求。成功返回一行样例；失败会说明**是哪个路由、什么原因**（key 无效 / 没登录 / 模型名不存在 / 额度不足），不再只丢一句「模型没有返回内容」。
- 两个入口互斥：选了 DSH provider 就清掉自填的 baseURL/apiKey；填了自填端点就清掉 provider。

不选就用 DSH 的默认模型（设置里的默认模型）。

## 能调什么

| 项 | 选项 | 说明 |
|---|---|---|
| 开关 | 开 / 关 | 只影响当前会话，不写盘；关掉后一个请求都不发 |
| 每隔 | 1 / 5 / 15 / 60 分钟 | 写进 `settings.json`，下次打开还是这个值 |
| 风格 | 毒舌 / 温柔 / 侦探 / 摆烂 | 同上，会记住 |

四条提示：

- **没有默认模型时会明说**，不会静默失败——去 DSH 设置里选一个默认模型即可。
- **间隔是硬门槛**：没到点不会调用模型，同一段文字反复出现也不会重复吐槽。
- **模型报错只在面板里显示一行红字**，正文照常能读，不会把阅读页带崩。
- **推理档位自动压到最低**：宿主默认模型常是 high，会吃光输出预算导致空回复；插件会取该模型支持的最低档位再发。

## 隐私

开启后，插件会把**你正在读的那一小段原文**发给模型（约 6 个自然段，上限 1200 字），用来生成吐槽。原文不会经过任何第三方中转，只发给你在 DSH 里配置的那一家模型服务商（或你自己填的端点）。

不想让原文离开本机，就别开这个开关——不开时插件完全不读、不存、不传任何阅读内容。
