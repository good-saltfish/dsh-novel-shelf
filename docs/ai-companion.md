# 小说书架 · AI 陪读

阅读器右侧栏里多了一块 **AI 陪读**：开着之后，AI 每隔一段时间就着「你刚读到的内容」吐槽一句。默认关闭——不开就一次都不会调用模型。

## 怎么用

1. 打开右侧栏的「小说书架」，进一本书。
2. 点底部工具栏的 **「AI 陪读」** 展开面板。
3. 点右上角开关打开（按钮会从「已关闭」变成「已开启」）。
4. 想立刻听一句就点 **「现在就说」**，不用等间隔。

## 能调什么

| 项 | 选项 | 说明 |
|---|---|---|
| 开关 | 开 / 关 | 只影响当前会话，不写盘；关掉后一个请求都不发 |
| 每隔 | 1 / 5 / 15 / 60 分钟 | 写进 `settings.json`，下次打开还是这个值 |
| 风格 | 毒舌 / 温柔 / 侦探 / 摆烂 | 同上，会记住 |

四条提示：

- **没有默认模型时会明说**，不会静默失败——去 DSH 设置里选一个默认模型即可。
- **间隔是硬门槛**：没到点不会调用模型，同一段文字反复出现也不会重复吐槽。
- **模型报错只在面板里显示一行红字**，正文照常能读，不会把阅读页带崩。
- 陪读用 DSH 当前默认模型，**没有单独配 key**；花费走你自己的模型额度。

## 隐私

开启后，插件会把**你正在读的那一小段原文**发给模型（约 6 个自然段，上限 1200 字），用来生成吐槽。原文不会经过任何第三方中转，只发给你在 DSH 里配置的那一家模型服务商。

不想让原文离开本机，就别开这个开关——不开时插件完全不读、不存、不传任何阅读内容。

## 自己看效果

```bash
npm test      # hosttest + smoke 双套件
```

测试覆盖：默认关闭不调模型、间隔门控、空回复报错、风格/间隔写回、模型失败不影响阅读、面板出错只显示一行错误。
